# 网校后台-用户

## 范围

用户管理、教师、认证审核、登录记录、微信粉丝、学习统计、注销账号等用户管理。

## 公共前置

1. 按 `zhixunbao-admin-core` 完成登录并保持会话。
2. 封禁/解封、注销、审核等操作影响用户权益，先核对对象与依据。
3. 禁止修改系统保护账号的密码/角色/邮箱。

## 常用操作速览

| 操作 | 后台入口 | 注意事项 |
|---|---|---|
| 用户列表 | `/admin/v2/user` | 支持关键词/角色/状态过滤 |
| 用户编辑 | 用户详情/编辑页 | 禁止修改保护账号 |
| 封禁/解封 | 用户操作按钮 | 会影响登录 |
| 认证审核 | `/admin/v2/user_approval` | 审核前核对材料 |
| 登录记录 | `/admin/v2/login_record` | 只读 |
| 微信粉丝 | `/admin/v2/wechat_fans` | 只读/打标签 |
| 学习统计 | `/admin/v2/learn_statistics` | 只读 |

## 结果验证

- 用户状态/角色/审核结果在详情页核对。
- 封禁后模拟登录/接口确认被拦截。
- 只读报表与列表数据一致。
