# 网校后台-数据

## 范围

数据概览、统计分析、高级仪表盘、导出报表等数据查看与分析。

## 公共前置

1. 按 `zhixunbao-admin-core` 完成登录并保持会话。
2. 数据类操作以只读为主；导出前确认权限与范围。

## 常用操作速览

| 操作 | 后台入口 | 注意事项 |
|---|---|---|
| 数据概览 | 首页或 `/admin/v2/data_statistics/overview` | 只读 |
| 数据统计 | `/admin/v2/data_statistics` | 按时间/维度切换 |
| 高级仪表盘 | `/admin/v2/dashboard_pro*` | 只读 |
| 导出 | 各统计页导出按钮 | 注意导出范围/权限 |

## 结果验证

- 数据与列表/详情页交叉核对。
- 导出文件行数、字段、时间范围正确。
- 关键指标口径与业务确认一致。
