# 网校后台-系统

## 范围

系统设置、用户/课程/运营/交易设置、合规设置、插件管理、存储配置、版本管理、缓存与日志等系统维护。

## 公共前置

1. 按 `zhixunbao-admin-core` 完成登录并保持会话。
2. 系统级修改影响全站，先确认影响面并备份/记录原值。
3. 支付、存储、插件等高风险配置需授权后操作。

## 常用操作速览

| 操作 | 后台入口 | 注意事项 |
|---|---|---|
| 网校信息 | `/admin/v2/school_information` | 品牌信息修改后全站生效 |
| 用户/注册设置 | `/admin/v2/setting/auth` | 谨慎修改注册/登录方式 |
| 课程设置 | `/admin/v2/setting/course` | 影响课程默认行为 |
| 支付设置 | `/admin/v2/setting/payment` | 资金相关，需授权 |
| 插件管理 | `/admin/v2/plugin_manager` | 启停前确认依赖 |
| 存储配置 | `/admin/v2/aliyun_storage/setting` | 测试连通后再保存 |
| 版本管理 | `/admin/v2/system_update` | 只读为主 |
| 缓存/优化 | 系统优化页或 Console 命令 | 不要删除整个缓存目录 |
| API 设置 | `/admin/v2/system/api/setting` | 开启需配置白名单 |

## 结果验证

- 设置保存后页面/接口实际生效验证。
- 插件启停后相关功能回归。
- 缓存清理后前台正常加载、无报错。
