# 职业教育课程大纲生成器

把「想开一门课」变成「可执行的模块化大纲」。核心原则：**结构人定，AI 只做整理与补全**——大纲里的知识边界、考试依据、行业判断由人确认，AI 负责结构化表达。

## 课程生成三铁律（2026-08-13 七哥确认，强制）

1. **知识点碎片化生成**：禁止一次性生成长课时课程。课程必须按「知识点」粒度拆解为独立单元（1 个知识点 = 1 个可独立生成/独立校验的场景片段），再在课时中组合成完整课时（1 课时 = 3-6 个知识点场景，20-40 分钟）。大纲输出必须同时给出「知识点清单」与「课时组合关系」。
2. **按教学大纲提炼知识点并验证正确**：知识点必须从已确认的教学大纲中提炼，逐条标注大纲出处；生成前核对知识点与大纲章节一一对应，生成后核对覆盖度与准确性；来源不确定处标 `needs_source`，禁止编造数据、案例、考点。
3. **考试类课程必须结合题库设置知识点**：考试/认证类课程必须先基于题库拆解知识点（题库模块 × 题型 → 考点 → 知识点），课时讲解与例题必须对应题库考点；题库未确认前不进入生成，课程不得脱离题库。

## 课程生成 SOP v3（2026-08-13 七哥确认，替代 v2）

> 修订要点：**禁止生产长课时视频**；以「知识点」为最小生成与课时单位；累计时长达标即可；课时标题 = 知识点名；配套 wiki 知识点（详情页课程介绍模块）；课程按系列/场景组成班级。

1. **大纲与题库确认**（考试类先做题库知识点地图）；
2. **生成 wiki 知识点**：按大纲拆知识点并写入 Wiki，作为详情页「课程介绍」模块之一；
3. **逐字稿/提示词**：每个知识点产出课程逐字稿（或结构化提示词：学习目标/内容要点/互动练习/案例）；
4. **知识点为单位生成**：EduOpenAI Core 按标准流程生成（1 知识点 = 1 课堂 = 1 短课时，禁止长视频）；
5. **时长校验**：累计课时数达标（总偏差 ±10 以内，如 8 课时课程 = 8-8.8 课时）；
6. **创建课时**：以知识点名称为标题创建智训宝互动课堂课时；
7. **组建班级**：按系列/场景组建智训宝班级（知识提升：xxx 基础班/进阶班；场景定制：女性 AI 知识应用班、国资企业 AI 定制班等）；
8. **记录**：wiki 知识点 / 逐字稿 / 课堂 ID / 课时 task ID / 班级 ID / 验收。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 课程主题 | 是 | 一句话（如「人工智能训练师三级备考课」） |
| 目标人群 | 是 | 谁学（在职转行/零基础/机构内训） |
| 学习目标 | 否 | 学完能做什么（通过考试/掌握工具/完成项目） |
| 考试/认证要求 | 否 | 如有（如「三级理论机考，判断/单选/多选，60 分合格」） |
| 参考题库/资料 | 考试类必填 | 考试类课程必须提供题库并按题库拆知识点（如 12 模块 × 3 题型）；缺失时先补题库再生成 |
| 教学大纲 | 是 | 已确认的大纲文件/章节结构，作为知识点提炼与验证依据 |

## 工作流

### 第 1 步：确认需求

- 主题、人群、目标各至少一句；
- 考试类课程：先确认题库来源与范围（模块、题型、考点），题库未就绪不进入下一步；
- 有考试则标注官方依据（证书等级、题型、合格线），不确定处标 `以官方最新通知为准`；
- 没有真实素材时标记 `needs_source`，不编造数字。

### 第 2 步：拆模块 → 提炼知识点清单（碎片粒度）

- 按知识域拆分 5-12 个模块（M01、M02…）；
- 每模块拆为「知识点清单」：每个知识点 = 独立单元（名称、目标、要点、对应大纲出处、对应题库考点/题型）；
- 考试类课程：知识点与题库模块/题型逐条对应，标注题库编号范围；
- 禁止把整课时作为一个知识点：知识点粒度必须可独立生成。

### 第 3 步：验证知识点（大纲/题库对应）

- 逐条核对：知识点 ↔ 大纲章节 一一对应（覆盖度 100%，无遗漏无越界）；
- 考试类：知识点 ↔ 题库考点/题型 对应，无脱离题库的知识点；
- 校验结论写入大纲（通过/需补素材/需修正）。

### 第 4 步：排课时 = 知识点组合

- 每课时由 3-6 个知识点场景组合（20-40 分钟），组合顺序遵循大纲课时结构；
- 每课时标注：组合的知识点清单、学习目标、内容要点、互动设计（测验/练习/案例）、产出物；
- 末尾加 1 节综合（模拟/复盘），同样按知识点碎片拆解。

### 第 5 步：配套练习与考核

- 每模块配练习（按题型或场景），题目/例题与题库考点对应；
- 设计 1-2 次综合考核（模考/项目），考试类考核题从题库抽取范围；
- 考核衔接真实考试/认证时注明官方口径。

### 第 6 步：输出大纲

```markdown
## 课程名称
- 定位：一句话
- 人群：…
- 课时数：N 课时（每课时 X 分钟）
- 三铁律校验：知识点碎片化 ✅ / 大纲验证 ✅ / 题库绑定 ✅（考试类）

### 模块总览
| 模块 | 主题 | 课时 | 学习目标 |

### 知识点清单（碎片粒度）
| 知识点 | 所属模块 | 大纲出处 | 题库考点/题型（考试类） | 是否可独立生成 |

### 逐字稿/提示词清单（每知识点一份）
| 知识点 | 逐字稿/提示词 | 目标时长 | 互动设计 |

### 课时对照表（标题 = 知识点名）
| 课时标题（=知识点） | 课堂 ID | 时长 | 累计时长校验 |

### 班级规划
| 班级 | 类型（系列/场景） | 包含课程 |

### 课时明细
#### 课时 N｜主题
- 知识点：K（标题 = 知识点名）
- 目标：…
- 要点：…
- 互动：…
- 产出：…

### 配套练习与考核
- 模块练习：…
- 综合考核：…
- 官方依据：…（以官方最新通知为准）
```

## 质量检查

- 每模块目标可验收（学完能做什么）；
- **无长课时视频**：每课时 = 1 个知识点短课时，累计课时数在目标 ±10 内（如 8 课时课程 = 8-8.8 课时）；
- **课时标题 = 知识点名**；
- **每知识点有逐字稿/提示词**且已生成 wiki 知识点；
- **知识点与大纲一一对应**：来源可核实，无编造，覆盖度 100%；
- **考试类与题库绑定**：每课时知识点/例题对应题库考点，课程未脱离题库；
- 课时粒度可排课（单课 20-40 分钟，由知识点组合）；
- 有考试依据时全部标注官方口径；
- 无编造数据/经历。

## 边界

- 不替代教师判断：知识结构最终由人确认；
- 不承诺考试结果：不写「包过」类表述；
- 考试类课程在题库未确认前不输出课时方案；
- 课程合规：涉及证书/补贴内容以官方最新通知为准。
