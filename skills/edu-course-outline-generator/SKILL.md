# 职业教育课程大纲生成器

把「想开一门课」变成「可执行的模块化大纲」。核心原则：**结构人定，AI 只做整理与补全**——大纲里的知识边界、考试依据、行业判断由人确认，AI 负责结构化表达。

## 输入

| 字段 | 必填 | 说明 |
|------|------|------|
| 课程主题 | 是 | 一句话（如「人工智能训练师三级备考课」） |
| 目标人群 | 是 | 谁学（在职转行/零基础/机构内训） |
| 学习目标 | 否 | 学完能做什么（通过考试/掌握工具/完成项目） |
| 考试/认证要求 | 否 | 如有（如「三级理论机考，判断/单选/多选，60 分合格」） |
| 参考题库/资料 | 否 | 有则按资料拆分模块（如 12 模块 × 3 题型） |

## 工作流

### 第 1 步：确认需求

- 主题、人群、目标各至少一句；
- 有考试则标注官方依据（证书等级、题型、合格线），不确定处标 `以官方最新通知为准`；
- 没有真实素材时标记 `needs_source`，不编造数字。

### 第 2 步：拆模块

- 按知识域拆分 5-12 个模块（M01、M02…）；
- 每模块标注：主题、核心知识点（3-6 条）、学习目标、对应资料/题库范围；
- 若有题库/资料，模块边界与资料章节对齐。

### 第 3 步：排课时

- 每模块拆 1-3 课时，每课时 30-60 分钟；
- 每课时标注：学习目标、内容要点、互动设计（测验/练习/案例）、产出物；
- 末尾加 1 节综合（模拟/复盘）。

### 第 4 步：配套练习与考核

- 每模块配练习（按题型或场景）；
- 设计 1-2 次综合考核（模考/项目）；
- 考核衔接真实考试/认证时注明官方口径。

### 第 5 步：输出大纲

```markdown
## 课程名称
- 定位：一句话
- 人群：…
- 课时数：N 课时（每课时 X 分钟）

### 模块总览
| 模块 | 主题 | 课时 | 学习目标 |

### 课时明细
#### 课时 N｜主题
- 目标：…
- 要点：…
- 互动：…
- 产出：…

### 配套练习与考核
- 模块练习：…
- 综合考核：…
- 官方依据：…（以官方最新通知为准）
```

## 质量检查

- 每模块目标可验收（学完能做什么）；
- 课时粒度可排课（单课 30-60 分钟）；
- 有考试依据时全部标注官方口径；
- 无编造数据/经历。

## 边界

- 不替代教师判断：知识结构最终由人确认；
- 不承诺考试结果：不写「包过」类表述；
- 课程合规：涉及证书/补贴内容以官方最新通知为准。
