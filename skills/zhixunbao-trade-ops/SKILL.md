# 网校后台-交易

## 范围

商品订单、退款、账单、虚拟币等交易管理。

## 公共前置

1. 按 `zhixunbao-admin-core` 完成登录并保持会话。
2. 退款/账单类操作涉及资金，必须按授权执行并保留证据。
3. 先核对金额、支付渠道、商品信息再操作。

## 常用操作速览

| 操作 | 后台入口 | 注意事项 |
|---|---|---|
| 订单列表 | `/admin/v2/order_manage` | 支持订单号/用户/状态过滤 |
| 订单详情 | 列表进入 | 核对金额/支付/商品 |
| 退款列表 | `/admin/v2/order_refunds` | 审核前核对支付渠道 |
| 账单 | `/admin/v2/bill` | 现金/虚拟币 Tab |
| 虚拟币 | `/admin/v2/coin_user_records` | 只读为主 |

## 结果验证

- 订单详情金额/状态/流水核对。
- 退款后支付渠道/订单状态同步核对。
- 账单导出与列表汇总一致。
