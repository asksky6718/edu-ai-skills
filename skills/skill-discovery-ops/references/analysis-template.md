# 技能分析报告模板

> 用途：评估某个技能是否值得安装时的六维分析框架；同时可直接作为 GitHub 平台运营素材（文章/README 正文）。

## 六维评估框架

| 维度 | 核实项 | 判定要点 |
|------|--------|---------|
| ① 来源与规模 | 仓库 owner、安装量、License、活跃度 | 官方来源优先；安装量 ≥1K；有 License；近期有提交 |
| ② 功能 | 读 SKILL.md 源码，真实能力与流程 | 与实际需求是否匹配；是否依赖外部 CLI/API |
| ③ 依赖 | 运行时/API key/MCP/hooks/平台 | Windows 兼容性；付费门槛；其他 agent 专属机制 |
| ④ 本机现状 | 现有技能/内置工具对照 | 是否已有同能力技能（查 `~/.codex/skills/` + Wiki 技能库） |
| ⑤ 重复/冲突 | 与内置工具或现有技能比对 | 重复度高→不装；互补→可装；冲突→不装 |
| ⑥ 结论 | 综合判定 | 推荐安装/可选/不装 + 理由 + 安装命令 |

## 报告结构（可直接发布）

```markdown
> 日期：YYYY-MM-DD

## 一、结论概览
<一句话结论：推荐/可选/不装 + 关键理由>

## 二、技能信息
| 项 | 值 |
|---|-----|
| 来源 | owner/repo |
| 安装量 | N K |
| License | ... |
| 功能 | ... |
| 依赖 | ... |

## 三、本机现状对照
<现有技能/内置能力，重复或互补判断>

## 四、风险与对策
<供应链/平台兼容/生态稳定性/成本>

## 五、结论与安装建议
<是否安装、安装命令、验证路径、回滚方式>
```

## GitHub 平台素材要点

- **标题**：动词开头 + 价值点（如「如何用 find-skills 一键发现并装好 AI 技能」）；
- **摘要**：2-3 句讲清解决什么问题、适用人群（职教 AI 从业者/agent 使用者）；
- **正文**：问题背景 → 方法（三查/冲突排除）→ 实战案例（真实安装量、实测数据）→ 经验教训；
- **代码块**：给出可直接复制的安装命令；
- **人设**：懂 AI 的职业教育架构师（GitHub 定位），突出「验证过才分享」的信用。
