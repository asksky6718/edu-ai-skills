# 网校后台-营销

## 范围

优惠券、订阅制会员、会员权益、邀请、分销、信息收集等营销管理。

## 公共前置

1. 按 `zhixunbao-admin-core` 完成登录并保持会话。
2. 涉及价格、面额、有效期等字段时先与业务确认。

## 常用操作速览

| 操作 | 后台入口 | 注意事项 |
|---|---|---|
| 优惠券列表/创建 | `/admin/v2/coupon` | 注意批次/面额/有效期 |
| 优惠券导出 | 列表页导出按钮 | 大导出走异步 |
| 订阅方案管理 | `/admin/v2/vip-subscription/plan` | 改价影响售卖 |
| 订阅订单查询 | `/admin/v2/vip-subscription/order` | 支持用户/状态过滤 |
| 会员权益 | `/admin/v2/member-benefit` | 与会员等级绑定 |
| 信息收集活动 | `/admin/v2/information_collect` | 开启/关闭前确认目标 |

## 结果验证

- 创建后列表/详情核对批次、状态、有效期。
- 前台活动入口/规则展示验证。
- 导出文件下载与行数核对。
