# 职业技能等级认定培训机构 · 成立全流程（vocational-training-school-setup）

> 一个把「办一所能做职业技能培训、并能开展职业技能等级认定的机构」**从立项跟到能持续运营**的 AI 技能包。
> 逐条用**官方公开口径**核你的推进表，输出「缺哪一步、哪步顺序错了、日期与状态是否合规」。
> 版本：**1.1.0** · 许可：MIT

---

## 一、它解决什么问题

办培训学校的坑不在「不会填表」，在于**资质是有先后顺序的**：

- **先有培训资质，才能招生**——未取得办学许可证或未经依法登记，不得面向社会开展职业培训活动；
- **先有法人登记，才算真的能开课**——拿到许可证只是一半；
- **消防、场地、师资、验资要提前确认**——装修完才发现场地不合规，是最贵的错；
- **「能办学」≠「能发证」**——能对外开展职业技能等级认定、发职业技能等级证书，是**另一套资质**（社评组织备案）；
- **各地口径不一样**——同一省内不同县市的面积门槛、资金门槛、办结时限都可能不同。

这个技能包把这些拆成**5 条能力**，能用机器核的先核完，缺的地方直接给你「插在第几步、谁负责、凭什么」。

## 三、两条铁律

1. **以属地当期公开文件为准。** 培训类审批按区/县级人社部门执行。技能里的湖北、上海两份口径**只作对照与提问用**，落地前必须取当地当期办事指南原文。
2. **两种资质别混为一谈。**
   - **办学许可（培训资质）**：解决「能不能面向社会办培训」
   - **社评组织备案（评价资质）**：解决「能不能面向社会做职业技能等级认定、发职业技能等级证书」

## 四、机器帮你干 / 必须你本人干

**机器全包**：属地口径检索与对照 · 推进表机械核对（资质链 / 日期 / 状态 / 空值 / 顺序倒置） · 交付物逐项打勾 · 缺口与催补清单 · 年检与台账排期 · 申报包结构配方。

**必须你（或审批机关）来**：取属地当期原件 · 场所与消防核实 · 验资与固定资产证明 · 教师劳动合同 · 单位盖章 · 提交申报 · 与审批机关对口径。

> 判断标准：**凡是要盖章、要签字、要花钱、要去现场的，机器不代办。**

## 五、安装

```bash
cp -r vocational-training-school-setup ~/.workbuddy/skills/    # WorkBuddy
cp -r vocational-training-school-setup ~/.codex/skills/        # Codex 系
```

装好后，对话里说「我要办个培训学校」「检查我的项目推进表」「缺什么材料」即可唤起。

## 六、脚本用法

```bash
# 核一份推进表（xlsx）
python scripts/gap_check.py --xlsx "<推进表.xlsx>" --region 湖北 --json-out gap.json
```

- 需要 `openpyxl`；**请在虚拟环境或已装 openpyxl 的解释器中运行**，脚本不会自动安装任何依赖。
- 只读你的表，只在给了 `--json-out` 时写一个 JSON；**不联网、不删文件**。
- 退出码：`0`＝无阻断，`1`＝存在阻断，`2`＝文件/依赖问题。

## 八、免责与边界

- 本技能**不代替审批部门解释政策**，**不承诺**办理结果、补贴金额、评审通过。
- 政策类数据一律回官方原文核，**不套模板、不照抄其他地区数字**。
- 案例与口径中的一切阈值**只作提问清单**，不作为属地标准。
- 对外材料**不含**主体名、客户名、地名绑定、人名、证件号。
