# 职业技能等级认定培训机构 · 成立全流程

按用户意图 **`Read`** 对应环节的 `SKILL.md`，再按该流程执行。**先查「路由判定表」定去向，再看「通则」。**

## 能力总览

| 能力 | 做什么 | 入口 |
|------|--------|------|
| **口径与路线** | 锁属地当期口径（审批机关 / 依据文号 / 材料来源）＋定资质路线（办学许可 only ／ 办学许可＋社评备案 ／ 仅社评） | `skills/scope-route/SKILL.md` |
| **推进表核对** | 跑机械核对脚本，输出四级缺口（资质链缺失 / 日期非法 / 状态越权 / 空值 / 顺序倒置） | `skills/gap-check/SKILL.md` |
| **交付物清单** | 按清单逐项打勾并标证据位置；给常见退回原因与缺件催补清单 | `skills/deliverables/SKILL.md` |
| **运行合规** | 年检、培训台账、培训协议、收费公示、变更与终止预案 | `skills/compliance/SKILL.md` |
| **评价资质** | 社评组织征集遴选的条件 / 材料 / 程序 / 红线（**须点名**） | `skills/evaluation/SKILL.md` |

## 两条铁律（先记住，再往下走）

1. **以属地当期公开文件为准。** 培训类审批按**区/县级**人社部门执行，同一省内不同县市的条件、材料、时限都可能不同。本技能的湖北、上海两份口径**只作对照与提问用**，落地前必须取当地当期办事指南原文。
2. **两种资质别混为一谈。**
   - **办学许可（培训机构资质）**：人社部门许可，解决「**能不能面向社会办培训**」。
   - **社评组织备案（评价资质）**：人社部门备案，解决「**能不能面向社会做职业技能等级认定、发职业技能等级证书**」。

   先有前者，通常才有资格谈后者；**没有办学许可不得招生办学**，**没有备案不得对外开展等级认定**。

## 路由判定表

「**须点名**」= 只有用户明确说出该行触发词才进入。

| 用户这样说 | 前置门禁（不满足就停下说明） | 进入 | 明确不要做 |
|------------|------------------------------|------|------------|
| 培训机构成立、办学校、办学许可、办学许可证、民办职业培训学校、职业工种申报、申办报告、审批机关是谁 | 无 | 口径与路线 | 不给任何数字门槛；不给跨地区套用的结论 |
| 推进表、进度表、检查我的推进表、缺什么、顺序对不对 | 需**指定推进表文件**（xlsx）；缺则先要文件，别凭描述猜 | 推进表核对（先跑 `scripts/gap_check.py`） | 不替用户改表；只出缺口清单与建议插入位置 |
| 材料清单、要交什么、会被退回什么、缺件催补、申报包怎么组 | 须先定资质路线 | 交付物清单 | 不生成虚假材料、不代填证件信息 |
| 年检、台账、培训协议、收费公示、变更、终止 | 须已取得办学许可 | 运行合规 | 不承诺年检结果与整改结论 |
| 社评组织、等级认定、评价机构备案、考核点、发职业技能等级证书 — **须点名** | 须是依法登记的独立法人（通常先有办学许可） | 评价资质 | 不得把「办学许可」当「评价资质」；不承诺备案通过 |
| 帮我全程办、一站式、集齐所有材料 | 先定资质路线，再逐环节推进 | 口径与路线 → 逐环节 | **不代办提交、不代签代盖、不承诺办理结果** |

## 通则

- **根只做路由**：本文件是「分诊台」，业务正文一律下沉到子技能与 `references/`。
- **六段统一**：每个 `skills/*/SKILL.md` 一律六段——**用途 / 何时用 / 输入 / 步骤 / 护栏 / 产出物**。
- **口径纪律**：结论后跟**依据**（文件名 / 文号 / 网址）；未取得原文的部分一律写「**待属地核**」，**不得用其他地区数字顶替**。
- **缺口三档**：阻断级（不做就不能合法招生） / 重要 / 建议；阻断级只列「不做就不能合法招生」的项。
- **金额类表述**：只给「以当地当期文件为准」，不给数字承诺、不给补贴承诺。
- **路径只写仓库相对路径**：整包 `python scripts/gap_check.py`；不写本机绝对路径。
- **交付末块统一**：各子技能交付回复末块标题一律 **「交付后请确认」**。
- **对外材料**：不出现未签约的第三方机构具名。

## 环境与约定

- **默认语言**：面向用户的结论、清单用简体中文。
- **属地粒度**：口径一律从**区/县级**起查，省市级文件只作上位依据。
- **脚本依赖**：`scripts/gap_check.py` 需要 `openpyxl`。**请在虚拟环境或已装 openpyxl 的解释器中运行**；脚本**不会自动安装任何依赖**，不联网、不删文件。
- **用户产出**：结果默认**只在对话里讲**，留文件时写当前工作区 `outputs/`。
- **版本口径**：流程或口径有变 → 升版本；只补发布要件 → 同样升版本；同时改 `VERSION` 与 `CHANGELOG.md`。
