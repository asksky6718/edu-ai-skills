# 推进表机械核对

## 用途
拿到一份推进表，**只做确定性检查**，输出「哪一行、什么问题、应该插在第几步、依据是什么」。**不替用户改表。**

## 何时用
- 用户说：检查推进表、进度表、缺什么、顺序对不对
- 已给到：**推进表文件路径（xlsx）**
（没给文件就停下先要，别凭口头描述猜表结构）

## 输入
| 项 | 形态 | 从哪来 | 缺了怎么办 |
|---|---|---|---|
| 推进表 | xlsx，含列：重点任务/具体事项/交付物/负责人/协同方/当前状态/验收标准/时间节点/备注 | 用户 | 停下要文件 |
| 属地 | 省/市/区县（可给，仅作报告抬头） | 用户 | 不给也能跑，报告里标「须以属地当期办事指南复核」 |
| 工作表名 | 可选 | 用户 | 不给则扫全部工作表 |

## 步骤
1. 跑脚本：

   ```bash
   python scripts/gap_check.py --xlsx "<推进表.xlsx>" --region <属地> --json-out gap.json
   ```

   退出码：`0`＝无阻断，`1`＝存在阻断，`2`＝文件/依赖问题。
2. 读报告，按四级分档：**阻断 / 重要 / 建议 / 提示**。阻断级只保留「不做就不能合法招生」的项。
3. 对每条阻断/重要，照 `references/checklist-and-gaps.md` 的「缺口处置模板」补齐：**建议插入位置 ＋ 交付物 ＋ 可判验收标准 ＋ 时间节点 ＋ 依据**。
4. 输出修订建议（不直接改用户的表）。

## 护栏
- **不改用户的表**：脚本只读，报告只写 `--json-out` 指定的 JSON。
- **不自动安装依赖**：缺 `openpyxl` 时报错退出，只在提示里说「请在虚拟环境或已装 openpyxl 的解释器中运行」。
- **不做主观评价**：脚本只输出事实（第几行、什么现象），分级结论由本环节给出并说明依据。

## 产出物
- 推进表机械核对报告（四级缺口表）＋ JSON（可选）
- 缺口补充清单（交付物 / 可判验收标准 / 时间节点 / 依据）
- 交给用户修订；补齐后转 `skills/deliverables/` 逐项打勾

## 交付后请确认
- 阻断级缺口请用户先认（这些是「不做就不能合法招生」的项）
- 需要插入的任务由谁负责、什么时候完成，需用户落到责任人
