# 网校后台-教学

## 范围

课程、班级、题库、练习、云资源、评价、话题等教学管理。

## 公共前置

1. 按 `zhixunbao-admin-core` 完成登录并保持会话。
2. 发布/下架/删除前先检查课时、价格、封面、订单等前置条件。

## 常用操作速览

| 操作 | 后台入口 | 注意事项 |
|---|---|---|
| 课程列表 | `/admin/v2/course_set/index` | 支持状态/关键词 |
| 发布课程 | 课程详情页发布按钮 | 先检查课时/价格/封面 |
| 关闭/下架课程 | 课程详情页操作 | 影响前台可见性 |
| 删除课程 | 课程详情页删除 | 高风险，先确认无订单 |
| 班级管理 | `/admin/v2/classroom/index` | 注意班级课程绑定 |
| 题库练习创建 | Console 命令 | 有预览模式，先预览 |
| 课程与题库绑定 | 课程编辑页“题库”Tab | 绑定前确认题库已发布 |

## 结果验证

- 发布后前台课程/班级可见性验证。
- 删除后确认无残留引用/订单关联。
- 题库绑定后进入课程详情核对。
